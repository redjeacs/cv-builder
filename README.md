## ✨ Features

* **Live Interactive Editor:** Fill out details dynamically and watch your resume update in real time.
* **Modern React & Vite Setup:** Lightning-fast local development and optimal production builds.
* **Component-Based Sections:** Easily update contact details, work experience, and educational background.
* **Client-Side Privacy:** All data stays local to your browser session, ensuring personal details remain private.

## 🛠️ Built With

* **HTML5:** Semantic structure for the layout with inputs and buttons.
* **CSS3:** Custom styling, grid/flexbox layout, and active state transitions.
* **Reactt** Component based frontend library for scalable codes.
* **Webpack 5:** Automated asset bundling, dependency resolution, and build optimization.

## 🚀 Installation & Getting Started

Follow these simple steps to get the project up and running on your local machine.

### 📋 Prerequisites
You only need a modern web browser (Chrome, Edge, Safari, or Firefox) and Git installed on your computer.

### 🔧 Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/redjeacs/cv-builder/
   ```

2. **Navigate to the project folder**
   ```bash
   cd cv-builder
   ```
   
3. **Install Dependencies**
   ```basj
   npm install
   ```

4. **Launch the application**
   ```bash
   npm run dev
   ```
  *Opens local live development server
